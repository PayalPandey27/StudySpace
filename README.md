StudySpace – Student Planner

About the Project

StudySpace is a student study planner web application developed to help students organize their academic activities efficiently. It provides a simple and user-friendly platform to manage daily tasks, create timetables, maintain study notes, and track academic progress.

Technologies Used

- HTML5 – For structuring the web pages.
- CSS3 – For styling and responsive design.
- JavaScript (ES6) – For functionality and interactivity.
- Web Storage API (localStorage) – For storing user data locally in the browser.

Features

- Dashboard: Displays today's tasks, completed tasks, pending tasks, and subjects.
- My Tasks: Add, manage, and track daily study tasks.
- Timetable: Organize subjects and study schedules.
- My Notes: Create and maintain study notes.
- Progress: Monitor task completion and study progress.
- Local Storage: Saves data in the browser so it remains available after refreshing the page.

How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open "index.html" in a web browser.
4. Start using StudySpace.
